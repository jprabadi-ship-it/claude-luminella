プライバシーポリシー

最終更新日: 2026-08-06

Claude Luminella（以下「本アプリ」）は、BRAIN MAGIC Luminella のグロウリングに Claude Code の状態を表示し、本体のボタンで操作の許可・拒否を行うアプリケーションです。本アプリにおける情報の取り扱いについて、以下のとおり定めます。

収集する情報

本アプリは、いかなる個人情報も収集・送信しません。具体的には、次のいずれも行いません。

  • 利用者の識別情報（氏名、メールアドレス、アカウント情報など）の取得
  • 利用状況の解析（アナリティクス、テレメトリ、クラッシュレポートの自動送信）
  • 広告の表示、および広告目的でのデータ利用
  • 第三者へのデータ提供・販売

本アプリ自身はネットワーク通信を行いません。ただし「押して話す」機能を使う場合、文字起こしに用いる音声モデルを初回に一度だけ取得するため、外部のソフトがインターネットに接続します。取得後は接続しません。

端末内に保存される情報

本アプリは、以下の情報を利用者の Mac 内にのみ保存します。これらが外部へ送信されることはありません。

内容保存場所
許可・拒否に使うボタンの番号、リングの色、待ち時間などの設定 ~/.claude/luminella/config.json
接続診断ログ（デバイスとの接続結果、通信エラーの内容） ~/.claude/luminella/daemon.log

診断ログは、デバイスが認識されない場合などの原因究明のために記録されます。ファイルはいつでも削除して構いません。サポートへお問い合わせいただく際にこのファイルの送付をお願いする場合がありますが、送付するかどうかは利用者の任意です。

Claude Code とのやりとり

本アプリは Claude Code の「フック」という仕組みを通じて連携します。Claude Code から本アプリへ渡されるのは、どの種類の出来事が起きたか（セッション開始、ツールの実行、許可の要求など）と、対象となるツールの名前のみです。

本アプリはこれらを画面表示の切り替えとボタン待ちの判断にのみ使用し、保存も送信もしません。会話の内容、実行されるコマンドの中身、ファイルの内容を読み取ることはありません。

Claude Code の設定ファイルの変更

メニューの「フックを導入」「フックを解除」を選んだ場合に限り、本アプリは ~/.claude/settings.json を書き換えます。

  • 変更は追記および本アプリが追記した項目の削除のみで、他のツールの設定には触れません。
  • 書き換える前に、タイムスタンプ付きのバックアップファイルを同じ場所に作成します。
  • 利用者が明示的にメニューを選んだときにしか実行されません。

音声の取り扱い（押して話す機能）

スティックを倒している間だけマイクから録音し、その音声をこの Mac の中だけで文字に変換します。

  • 録音した音声も、変換したテキストも、外部へ送信されることはありません。
  • 録音した音声ファイルは、テキストへの変換が終わった時点で削除されます。
  • 変換したテキストはクリップボードに入ります。それ以外の場所へは保存しません。
  • 録音はスティックを倒している間だけです。常時マイクを開いていることはありません。

本機能には macOS の「マイク」の許可が必要です。本機能を使わない場合、許可は一切必要ありません。

文字起こしには外部のソフト（ffmpeg および mlx-whisper）を利用します。これらは利用者ご自身で導入いただくもので、本アプリには同梱していません。音声モデルの初回取得時のみ、これらがインターネットに接続します。

入力欄への直接入力

設定で有効にした場合、文字起こしした内容を、入力中のアプリへ貼り付けます。macOS の「操作の許可」（System Events）が必要です。

  • 送るのは Cmd+V の1回だけです。それ以外のキー操作は送りません。
  • 送るのは、文字起こしが完了した直後だけです。
  • 貼り付け先の画面の内容を読み取ることはありません。
  • メニューの「入力欄に直接入力」で無効にできます。無効の場合、キー操作は一切送らず、許可も不要です。

入力内容の取り扱い

本アプリは macOS の「入力監視」の許可を要求しません。この許可がない以上、キーボードの入力を読み取ることは技術的にできません。上記の直接入力はキー操作を送るだけで、読み取りは行いません。

本アプリが読み取るのは、USB シリアル接続を通じて Luminella 本体から送られてくる情報（どのボタンが押されたか、スティックがどの位置にあるか）と、押して話す機能の使用中のマイク入力のみです。これらは許可・拒否の判定と文字起こしにのみ使用します。

権限の用途

使い方必要な権限
状態表示と許可・拒否だけなし
押して話す（クリップボードへ）マイク
押して話す（入力欄へ直接）マイク、操作の許可

いずれも、その機能を使うときにのみ要求されます。

費用と外部サイト

本アプリは無料で配布しており、アプリ内での決済は一切行いません。開発者が支払い情報を取得することもありません。

製品ページには GitHub および Amazon のほしい物リストへのリンクがあります。これらのリンクを開いた場合、リンク先での情報の取り扱いは各サービスのプライバシーポリシーに従います。本アプリからこれらのサービスへ情報が送信されることはありません。

本ポリシーの変更

本ポリシーを変更する場合は、本ページの最終更新日を改めるとともに、変更内容を記載します。
