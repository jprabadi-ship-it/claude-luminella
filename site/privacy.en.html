Privacy Policy

Last updated: 2026-08-06

Claude Luminella ("the app") shows Claude Code's state on the glow ring of a BRAIN MAGIC Luminella and lets you approve or deny operations with the device's buttons. This policy describes how the app handles information.

Information collected

The app collects and transmits no personal information whatsoever. Specifically, it does none of the following:

  • Collect identifying information (name, email address, account details)
  • Analyse usage (analytics, telemetry, automatic crash reporting)
  • Display advertising, or use data for advertising purposes
  • Provide or sell data to third parties

The app itself makes no network connections. If you use push to talk, the external transcriber fetches its speech model once, the first time; after that it connects to nothing.

Information stored on your Mac

The app stores the following only on your own Mac. None of it is transmitted anywhere.

ContentLocation
Which buttons approve and deny, ring colours, timeout, and other settings ~/.claude/luminella/config.json
Connection diagnostics (connection results, communication errors) ~/.claude/luminella/daemon.log

The diagnostic log exists to help work out why a device is not being recognised. You may delete the file at any time. Support may ask you to send it, but doing so is entirely your choice.

What Claude Code passes to the app

The app integrates through Claude Code's "hooks" mechanism. What Claude Code passes to it is only which kind of event occurred (session started, a tool ran, approval requested) and the name of the tool involved.

The app uses these solely to change what the ring shows and to decide when to wait for a button. It neither stores nor transmits them. It does not read conversation content, the contents of commands being run, or the contents of files.

Changes to the Claude Code settings file

Only when you choose "Install hooks" or "Remove hooks" from the menu does the app modify ~/.claude/settings.json.

  • Changes are additions only, plus removal of the entries the app itself added. Other tools' settings are left untouched.
  • A timestamped backup is written alongside the file before any change.
  • This happens only when you explicitly choose the menu item.

Audio (push to talk)

Audio is recorded only while the stick is held over, and is turned into text entirely on this Mac.

  • Neither the recording nor the resulting text is ever transmitted anywhere.
  • The recording is deleted as soon as it has been transcribed.
  • The text is placed on the clipboard and stored nowhere else.
  • Recording happens only while the stick is held. The microphone is never left open.

This feature requires macOS microphone permission. If you do not use it, no permission is needed at all.

Transcription uses external tools (ffmpeg and mlx-whisper) that you install yourself; they are not bundled with the app. Those tools reach the network only to fetch the speech model the first time.

Typing into the focused field

When enabled, the transcript is pasted into whatever application you are typing in. This requires macOS automation permission (System Events).

  • The only thing sent is a single Cmd+V. No other keystroke is ever sent.
  • It is sent only immediately after a transcription completes.
  • The app does not read anything from the window it pastes into.
  • It can be switched off from the menu. With it off, no keystroke is sent and no permission is required.

Handling of input

The app does not request macOS Input Monitoring permission. Without it, reading your keyboard is technically impossible. The paste above only sends a keystroke; it never reads one.

The only input it reads is what the Luminella itself sends over the USB serial connection — which button was pressed and where the stick is — plus the microphone while push to talk is held. These are used only to decide approvals and to transcribe speech.

Cost and external sites

The app is distributed free of charge and contains no in-app payments. The developer receives no payment information.

The product page links to GitHub and to an Amazon wish list. If you follow those links, information there is handled under each service's own privacy policy. The app itself sends nothing to those services.
