Clauminella

Luminella を Claude Code のステータスランプと承認ボタンにする。
倒して喋れば、そのまま文字になる。

無料でダウンロード できること

macOS 26 以降 / Apple Silicon 専用 / BRAIN MAGIC Luminella が必要

できること

Claude Code は考えている間、画面上ではほとんど動きません。その状態を手元のリングに出します。

状態が色で分かる

待機・実行中・許可待ち・エラー・完了を、グロウリングの色と光り方で表示します。ターミナルを見ていなくても進み具合が分かります。

点滅していたら止まっている

色だけでなく動きでも区別します。点灯は安定した状態、ゆっくりした呼吸は動作中、速い点滅はあなたの操作待ち。視界の端でも判別できます。

物理ボタンで許可・拒否

許可プロンプトが出るとリングが橙に点滅します。ボタンを1つ押せば許可、別のボタンで拒否。キーボードに手を戻す必要がありません。

専用ソフトが要りません

Luminella Core を介さず、デバイスと直接通信します。プロファイルの設定もキー割り当ても不要で、インストールしたら光ります。

ボタンは押して割り当て

番号を調べる必要はありません。メニューから割り当てを選び、リングが光っている間に使いたいボタンを押すだけです。

フックはワンクリックで導入

Claude Code の設定ファイルへの追記をアプリが行います。既存のフックには触れず追記のみ、実行前に自動でバックアップを取ります。解除も同じくワンクリックです。

止まらないように作ってあります

アプリを終了しても、デバイスを抜いても、Claude Code は普段どおり動きます。応答がなければ画面のプロンプトに委ねるだけで、物理ボタンが必須の関門にはなりません。

抜き差しに追従します

ケーブルを抜くと接続が切れたことを検知し、挿し直すと自動で復帰します。アプリを起動し直す必要はありません。

押して話す

スティックを倒している間だけ録音し、戻すと文字に起こして、入力中の欄にそのまま書き込みます。クリップボードにも残ります。長いプロンプトを打つ代わりに、手元で喋るだけ。音声はこの Mac の中だけで処理されます。

メニューバーだけ

Dock には出ません。メニューバーのアイコン自体が現在の状態を示します。Claude Code の起動時にアプリが立ち上がるので、常駐させておく必要もありません。

状態と色

色は用途に合わせて変更できます。光り方は3種類、点灯・呼吸・点滅です。

色光り方状態あなたがすること
暗い青点灯待機中。入力待ち指示を出す
シアン呼吸思考中・ツール実行中待つ
橙点滅許可待ち。止まっています許可または拒否ボタンを押す
紫点滅通知画面を見る
赤点灯拒否した／エラー状況によります
緑点灯許可した／応答完了—
ピンクゆっくり点滅マイク準備中まだ話さない
ピンク点灯録音中倒したまま喋る
青紫点滅文字起こし中1秒ほど待つ

許可待ちで30秒操作がなければ、リングは実行中に戻り、通常どおり画面のプロンプトで操作できます。待ち時間も変更できます。

必要な環境

状態表示と許可・拒否だけなら、macOS の特別な許可は必要ありません。アクセシビリティも入力監視も使いません。

権限使う機能によります（下表）

Luminella のリンクは Amazon アソシエイトのリンクです。Amazon のアソシエイトとして、適格販売により収入を得ています。 リンクを経由しても購入価格は変わりません。

権限

必要になるのは、その機能を使うときだけです。

使い方必要な権限
状態表示と許可・拒否だけなし
押して話す（クリップボードへ）マイク
押して話す（入力欄へ直接）マイク＋操作の許可

入力欄への直接入力は、キー操作（Cmd+V）を送るため macOS の操作許可が必要です。 メニューでいつでも切り替えられ、オフにすればキー操作は一切送りません。 その場合もクリップボードには入るので、貼り付ければ同じことができます。

押して話す機能を使う場合

この機能だけは外部のソフトが必要です。アプリには同梱していません。

用途導入
録音brew install ffmpeg
文字起こしpip install mlx-whisper

文字起こしの本体は 180MB、音声モデルは 1GB を超えます。22MB のアプリに同梱すると釣り合わないため、外部から呼び出す形にしています。 初回にモデルを取得するときだけネットワークに接続します。それ以降は通信しません。

マイクについて

USB 接続のマイクを直結するのが確実です。実測した起動時間の差は、体感ではっきり分かります。

接続方法録音が始まるまで
USB マイク直結約 0.5 秒
iPhone（Continuity）1.8〜8.6 秒

スティックを倒してから、実際に声が録れるようになるまでの時間です。それ以前は録音されません（空白が入るのではなく、存在しません）。 Continuity は iPhone がスリープしていると数秒かかるため、話し始めが丸ごと失われます。 リングが点灯に変わるまで待てば取りこぼしませんが、毎回数秒待つのは実用的ではありません。

開発に使っているのは FIFINE A8 です。 起動 0.5 秒で、固有名詞も取りこぼしませんでした。特定の製品でなければ動かないということはなく、 USB で直結できるマイクであれば同様に速いはずです。

Amazon のアソシエイトとして、適格販売により収入を得ています。

Luminella Core との同時使用はできません。 同じシリアルポートを取り合うため、どちらか一方だけが動作します。 Luminella を Claude Code 用として使う間は Luminella Core を終了してください。

音声はこの Mac の中だけで処理され、外部に送信されることはありません。 アプリ自身がネットワーク通信を行うこともありません。詳しくはプライバシーポリシーをご覧ください。

よくある質問

Luminella Core と併用できますか？

できません。どちらもデバイスのシリアルポートを占有するため、同時には動作しません。Luminella Core が起動している間、このアプリは「デバイス: 未接続」と表示します。Luminella Core を終了してから、メニューの「デバイスに再接続」を選んでください。

Orbital2 や Orbital2 STERNA でも動きますか？

確認していません。通信方式は共通のようですが、動作を検証したのは Luminella のみです。Orbital2 には振動モーターやロータリーエンコーダーなど Luminella にない機構があり、そのあたりの挙動も未検証です。試された結果を教えていただけると助かります。

アプリを終了したら Claude Code は動かなくなりますか？

いいえ、普段どおり動きます。フックはアプリに接続できなければ何も返さずに終了し、許可の判断は通常どおり画面のプロンプトで行われます。デバイスを抜いた場合や、許可待ちで時間切れになった場合も同じです。物理ボタンを押さないと先に進めない、という状態にはなりません。

既存のフック設定は壊れませんか？

触りません。設定ファイルには追記のみを行い、他のツールのフックはそのまま残します。書き換える前にタイムスタンプ付きのバックアップを作るので、いつでも戻せます。メニューの「フックを解除」を選ぶと、追記した項目だけを削除します。

遠隔承認ツールと併用できますか？

同じイベントに複数の承認ツールを登録すること自体は可能で、設定上は共存します。ただし両方が同時に判断を返そうとした場合の優先順位までは検証できていません。確実に動かしたい場合は、どちらか一方だけを有効にすることをおすすめします。

どうやってデバイスを制御しているのですか？

Luminella は USB シリアルデバイスとして接続されており、9600 baud のシリアル通信で LED の色を指定し、ボタンの押下を受け取っています。この通信仕様は公開されていないため、設定ソフトの通信内容を調べて把握し、実機で検証しました。分かった範囲はリポジトリに記載しています。

押して話す機能には何が必要ですか？

マイクの許可と、ffmpeg（録音）、mlx-whisper（文字起こし）です。どちらも brew install ffmpeg と pip install mlx-whisper で入ります。文字起こしの本体とモデルで 1GB を超えるためアプリには同梱していません。この機能を使わなければ、いずれも不要です。

喋った音声はどこかに送られますか？

送られません。文字起こしはこの Mac の中で完結します。ネットワークに接続するのは、初回に音声モデルを取得するときだけです。録音した音声はテキストに変換したあと削除されます。

入力欄への直接入力をやめられますか？

やめられます。メニューの「入力欄に直接入力」を切ればクリップボードに入るだけになり、キー操作は一切送らなくなります。操作の許可も不要です。既定では有効ですが、有効にする前に確認が出ます。

キー入力を記録していませんか？

していません。macOS の入力監視権限を要求しないため、キーボードの入力を読むことはできません。読み取るのは Luminella 本体のボタンとスティックと、押して話す機能を使っている間のマイクだけです。入力欄への直接入力を有効にした場合、キー操作を送ることはありますが、読み取ることはありません。

本当に無料ですか？

はい。機能制限も、試用期限も、広告もありません。ソースコードは GPLv3 で公開しているので、自分でビルドして使うことも、改変して再配布することもできます（改変版も GPLv3 で公開する必要があります）。
